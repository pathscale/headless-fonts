# headless-fonts

A fixed, versioned set of open fonts (Gelasio, Noto Sans, Noto Mono, Noto Sans Devanagari) compiled into the binary, plus the table of CSS family names each one stands in for (Georgia and serif, system-ui and sans-serif, ui-monospace and monospace, Devanagari fallback). For headless rendering that must look the same on every machine.
